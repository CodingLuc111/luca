Installation

Die Erweiterung wird als entpackter Ordner geladen. Das ist der offizielle Weg für ZIP-Verteilung in Chrome.

  1. ZIP auf der Download-Seite speichern.
  2. Rechtsklick auf die Datei → Alle extrahieren. Unter macOS genügt ein Doppelklick. Der Ordner muss danach bestehen bleiben.
  3. Adresszeile öffnen, chrome://extensions eingeben.
  4. Oben rechts Entwicklermodus aktivieren.
  5. Entpackte Erweiterung laden anklicken und den entpackten Ordner auswählen.
  6. Icon in der Toolbar öffnen, Funktionen einschalten.

Hinweise

Wird der Ordner gelöscht oder verschoben, verliert Chrome die Erweiterung. Lege ihn also an eine Stelle, die bleibt.

Updates laufen identisch: neues ZIP entpacken, alten Ordner ersetzen, in chrome://extensions auf „Aktualisieren" klicken.

Edge und Brave funktionieren genauso. Beide laden entpackte Erweiterungen über die gleiche Seite.
